# Spec Delta

## Purpose

让相同的语音输入流程可选择本地或 OpenAI 兼容识别服务，定义音频提交、语言、识别结果、取消和失败边界，同时保证服务切换不会把用户选择的本地录音暗中发送到网络。

## ADDED Requirements

### Requirement: 一致的服务行为
应用 SHALL 通过统一的识别契约处理音频、语言和结果；会话开始时固定 Provider 及有效设置，不在识别过程中混用新旧配置。

#### Scenario: 录音中改变服务
- **WHEN** 用户在当前录音开始后保存另一 Provider
- **THEN** 当前会话沿用开始时的服务，下一次使用新服务

### Requirement: OpenAI Compatible 转录
在线服务 SHALL 以用户配置的 Base URL、Model、可选 API Key 和 Language 向兼容的 audio/transcriptions 端点提交 WAV；自动语言检测时不强制指定语言，仅读取转录文本，不执行翻译或润色。

#### Scenario: 自定义 v1 服务器
- **WHEN** Base URL 为 http://localhost:8000/v1，服务器不需要 API Key
- **THEN** 请求正确发送至 /v1/audio/transcriptions，包含文件和模型，不发送空 Bearer 凭据

#### Scenario: 官方式服务器
- **WHEN** Base URL 为 https://api.openai.com/v1，模型与凭据有效
- **THEN** 请求使用配置凭据并解析兼容 JSON 的 text 字段

### Requirement: 在线错误与取消
在线识别 SHALL 对认证、限流、网络、超时、响应格式及空结果返回明确错误，并支持取消；第一版不自动重试付费转录请求。

#### Scenario: 超时或非 JSON 响应
- **WHEN** 请求超过 120 秒，或服务器返回无法解析的结果
- **THEN** 显示服务错误，不注入、不记录凭据或音频，恢复可重试状态

#### Scenario: 空文本
- **WHEN** 服务成功返回但 text 为空白
- **THEN** 显示未检测到语音，不写剪贴板或发送按键

### Requirement: 单模型本地转录
本地识别 SHALL 支持用户手动指定或在设置主动下载/导入的多语言 base 模型和 CPU 推理，不默认下载模型、不联网转录；模型缺失、损坏或不兼容时给出明确提示。

#### Scenario: 中文离线输入
- **WHEN** 网络断开且有效多语言 base 模型已配置，用户说“你好，这是一个语音输入测试”
- **THEN** 本地识别得到可供输入的中文文本，不向网络发送音频

#### Scenario: 没有模型
- **WHEN** 本地模型路径不存在
- **THEN** 提示配置模型，保持本地模式，不自动切换在线服务

### Requirement: 用户主动安装与管理本地模型
设置 SHALL 列出当前支持的多语言 base 模型，显示大小、语言、用途和来源；提供用户选择官方源或第三方镜像、下载进度、取消、失败重试、导入、使用、打开目录、确认删除与刷新状态。下载与导入 SHALL 在完整大小、SHA-256 与模型类型校验通过后原子安装，不覆盖已有文件；操作失败或取消清理临时文件。使用只保存本地 Provider 和模型路径，下一次会话生效。

#### Scenario: 下载并使用
- **WHEN** 用户选择下载来源并下载完整模型，然后点击使用
- **THEN** 文件通过上游哈希和模型头校验后显示已安装，下一次语音输入使用该模型；下载不提交录音或在线 API Key

#### Scenario: 取消或下载损坏
- **WHEN** 用户取消下载、网络出错、下载过大/截断或哈希不符
- **THEN** 不安装无效文件，清理临时文件，显示可重试提示，不改动已保存配置

#### Scenario: 导入与删除
- **WHEN** 用户导入已有文件或确认删除程序目录模型
- **THEN** 导入保留原文件并校验安装；删除不影响外部模型文件，活跃模型 lease 或推理期间拒绝删除，空闲时先卸载缓存

#### Scenario: 退出时下载中
- **WHEN** 下载进行时关闭设置或显式退出
- **THEN** 关闭设置继续下载；显式退出取消操作并等待临时文件清理

### Requirement: 本地资源与取消
本地识别 SHALL 串行执行，重复使用仍有效的已加载模型，在停用本地服务、变更模型、空闲 5 分钟或退出时安全释放模型；取消后禁止迟到结果注入，不在推理未结束时释放其资源。

#### Scenario: 连续两次识别
- **WHEN** 两次录音间隔小于 5 分钟且模型未变
- **THEN** 第二次不重复加载相同模型，两个请求不并发使用同一推理上下文

#### Scenario: 本地处理中取消
- **WHEN** 用户取消本地识别而原生推理尚未结束
- **THEN** 结果不发送，界面提示取消或清理状态，资源直到推理结束后才可释放或复用
