# Spec Delta

## Purpose

提供 Windows 常驻语音输入应用的生命周期，让用户从托盘访问设置与输入操作，同时确保关闭设置不会中断后台服务，只有显式退出才释放全部系统资源并结束应用。

## ADDED Requirements

### Requirement: 托盘常驻
应用 SHALL 在启动后显示系统托盘图标，默认隐藏设置与语音浮层，提供 VoxType 标识、开始语音输入、设置、退出及分隔线。

#### Scenario: 默认启动
- **WHEN** 用户启动应用
- **THEN** 托盘出现 VoxType，设置和浮层保持隐藏，服务准备就绪后可使用快捷键

#### Scenario: Shell 重启
- **WHEN** Explorer 重启导致托盘图标消失
- **THEN** 应用重建托盘图标，仍可继续使用

### Requirement: 设置窗口关闭后保持运行
应用 SHALL 从托盘打开可交互的设置窗口，并在关闭该窗口时隐藏窗口、保持后台服务运行。

#### Scenario: 关闭设置后输入
- **WHEN** 用户关闭设置窗口后在记事本按住快捷键
- **THEN** 应用仍能开始下一次语音输入

### Requirement: 托盘发起单次录音
应用 SHALL 允许托盘“开始语音输入”发起单次录音，并提供浮层上的“结束并识别”控制及 ESC 取消，不要求用户保持鼠标按下，不增加全局 toggle 快捷键模式。

#### Scenario: 从托盘发起
- **WHEN** 用户从一个输入框打开托盘菜单并选择开始语音输入
- **THEN** 菜单关闭后录音开始，浮层提供结束控制，输入目标取自托盘交互之前的有效外部窗口

#### Scenario: 缺失外部目标
- **WHEN** 无法确定托盘交互前的输入目标
- **THEN** 不把托盘或设置窗口作为目标，提示用户先聚焦输入框并使用快捷键

### Requirement: 单实例与显式退出
应用 SHALL 避免多个实例同时占用快捷键和麦克风，并在托盘退出时取消当前任务、移除托盘、释放录音和系统监听资源。

#### Scenario: 重复启动
- **WHEN** 应用已经运行，用户再次启动
- **THEN** 保留单个后台实例和单个托盘图标

#### Scenario: 处理中退出
- **WHEN** 识别尚未完成时用户选择退出
- **THEN** 后续结果不会输入，后台资源释放并终止应用
