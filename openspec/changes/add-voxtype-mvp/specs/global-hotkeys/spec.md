# Spec Delta

## Purpose

让用户在普通 Windows 桌面应用中可靠控制语音会话，定义组合键按下、松开、取消及异常中断的可观察行为，避免重复触发、丢失松开事件与系统快捷键意外执行。

## ADDED Requirements

### Requirement: 按住说话与松开识别
应用 SHALL 默认以 Ctrl + Win + F8 执行 push-to-talk，只在组合键首次完整按下时启动一次录音，在主键或必要修饰键松开使组合失效时停止并识别一次。

#### Scenario: 标准顺序
- **WHEN** 用户按住 Ctrl 和 Win，再按住 F8，说话后先松开 F8
- **THEN** 只启动一次录音，松开 F8 后停止并进入识别

#### Scenario: 先松开修饰键
- **WHEN** 用户录音时先松开 Ctrl 或 Win 再松开 F8
- **THEN** 必要修饰键松开即结束录音，F8 后续松开不重复结束

#### Scenario: 自动重复和快速轻按
- **WHEN** 用户长按产生重复 key-down，或在录音初始化完成前松键
- **THEN** 不创建重复会话，快速轻按不会留下持续录音或未释放的麦克风

### Requirement: 不泄漏被处理的组合键
应用 SHALL 在接管语音快捷键时避免向目标发送该主键的重复按下及对应松开，保持无关按键和普通 Alt / Space 行为；第一版的快捷键仅支持修饰键先按、主键后按的顺序。

#### Scenario: 保持目标输入框
- **WHEN** 在记事本执行默认 Ctrl + Win + F8 录音，或配置的 Alt + Space 录音
- **THEN** 不执行目标的主键动作，不打开系统窗口菜单、不插入额外空格、不遗留修饰键状态

#### Scenario: 主键先按
- **WHEN** 用户先按 Space 再按 Alt
- **THEN** 不开始录音，已发生的普通 Space 输入不被回溯撤销

### Requirement: 可配置组合键
应用 SHALL 支持至少一个 Alt、Ctrl、Shift 或 Win 修饰键加一个非修饰主键的配置，提示避免系统和编辑器已占用组合，对无效配置保留旧配置；保存后的有效组合从下一次空闲会话生效。

#### Scenario: 旧默认迁移
- **WHEN** 首次读取版本 1 的 Alt + Space 默认配置
- **THEN** 升级为版本 2 的 Ctrl + Win + F8，保留 Provider、模型路径及加密密钥；其他自定义组合和版本 2 中主动选择的 Alt + Space 保留

#### Scenario: 修改快捷键
- **WHEN** 用户保存 Ctrl + Alt + Space
- **THEN** 空闲后新组合能启动录音，旧组合不再启动录音

#### Scenario: 无效配置
- **WHEN** 用户提交仅修饰键、无修饰字符键、ESC / F12 主键或未知修饰位
- **THEN** 设置显示错误，旧快捷键仍可使用

### Requirement: 取消和忙碌期间的输入
应用 SHALL 在录音或识别期间提供 ESC 取消，取消后不再注入该会话结果；忙碌期间新的快捷键请求不创建并行会话。

#### Scenario: 识别时取消
- **WHEN** 用户松键开始识别，随后按 ESC
- **THEN** 浮层隐藏，迟到的识别结果不发送到目标

#### Scenario: 忙碌时再次按键
- **WHEN** 识别中再次按住并松开组合键
- **THEN** 不启动第二次录音，原任务结束后等待新的完整按键序列

### Requirement: 异常中断恢复
应用 SHALL 在锁屏、休眠、录音设备失效或录音达到 60 秒安全上限时结束或取消会话，解除旧按键序列后允许再次录音。

#### Scenario: 被拦截主键的异步状态
- **WHEN** 主键被 Hook 拦截，异步键状态轮询未报告主键按下，但必要修饰键仍按住
- **THEN** 不误取消录音；主键 Hook key-up 正常结束，修饰键丢失仍能中断，ESC 保持成对处理

#### Scenario: 锁屏
- **WHEN** 录音期间系统锁屏
- **THEN** 录音取消且不上传或注入，解锁并重新按下组合键后可再次开始

#### Scenario: 达到时长上限
- **WHEN** 连续录音达到 60 秒
- **THEN** 自动停止并识别已捕获音频，显示已到上限，仍按住的键不触发新会话
