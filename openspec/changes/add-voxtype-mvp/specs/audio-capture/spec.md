# Spec Delta

## Purpose

向语音识别链路提供来自真实麦克风的完整音频和实时音量，并定义没有有效语音、设备不可用以及录音中断时的结果，使 UI 不依赖任何具体音频捕获库或设备实现。

## ADDED Requirements

### Requirement: 录音与标准音频输出
应用 SHALL 从 Windows 默认录音设备捕获本次会话，停止时交付完整的 16 kHz、单声道、16-bit PCM WAV 数据；录音停止或取消后释放设备。

#### Scenario: 完成录音
- **WHEN** 用户结束一段有效录音
- **THEN** 输出含合法 WAV 头及完整末尾样本的数据，下次录音重新可用

#### Scenario: 默认设备格式不同
- **WHEN** 默认设备使用立体声或其他采样率
- **THEN** 识别收到相同的标准音频格式，时长与原始录音一致

### Requirement: 实时音量
应用 SHALL 在录音期间持续提供真实采样得到的音量，波形随麦克风信号变化；停止后不继续输出本次会话的音量。

#### Scenario: 说话与安静
- **WHEN** 用户在录音中交替说话和保持安静
- **THEN** 波形能分别呈现音量变化及安静时回落

### Requirement: 过短录音与低信号处理
应用 SHALL 拒绝不足 250 毫秒或全程低于低信号阈值的音频，提示“未检测到语音”，不调用识别或注入；低信号检测不宣称能够准确区分所有噪声和语音。

#### Scenario: 没有说话
- **WHEN** 用户松键后录音未达到最低时长或没有有效信号
- **THEN** 显示未检测到语音，然后自动隐藏并恢复待机

### Requirement: 麦克风失败可恢复
应用 SHALL 将设备缺失、访问被禁用或录音中设备断开转换为明确错误，并允许修复设备后重试。

#### Scenario: 设备被拔出
- **WHEN** 录音过程中麦克风断开
- **THEN** 会话停止，显示设备错误，不发送不完整音频；设备恢复后下一次录音可用
