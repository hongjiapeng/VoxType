# 真实系统验收表

每次记录 Windows 版本、缩放/屏幕、目标应用、Provider、模型或服务器及结果；不记录 API Key、私人转录内容或录音。完整手工链路仍待验收；真实设备开关及合成中文模型推理的局部结果见 verification.md，不当作完整验收通过。

## 核心 16 步

分别使用真实在线 Provider、真实本地多语言 base 模型各执行一次；每种连续执行 10 次。

1. 从 project-mode 启动 VoxType。
2. 确认仅托盘，设置/浮层未出现。
3. 托盘打开设置，填写有效 Provider 配置。
4. 保存并关闭设置，进程仍驻留。
5. 打开普通权限记事本。
6. 点击空白编辑区域，记录可见外部 foreground HWND。
7. 按住 Ctrl、Shift 和 Space（或设置中保存的自定义组合）。
8. 浮层出现，记事本保持前台。
9. 麦克风捕获真实音频。
10. 说“你好，这是一个语音输入测试”。
11. 说话/停顿对应真实波形变化。
12. 松开组合键，录音结束；识别期间显示进度环。
13. 获得真实中文识别结果。
14. 记事本出现识别文本；核对无系统菜单、额外空格或重复全文。
15. 浮层自动隐藏，记事本仍可继续输入。
16. 再次录音无需重新打开 VoxType。

## 自动 UI 检查

Debug 构建提供独立测试 profile 与静态浮层参数。先退出已有开发实例，再运行下列命令，使用返回的真实 PID：

```powershell
$profileId = [guid]::NewGuid().ToString('N')
winapp run src/VoxType.App/VoxType.App.csproj --arch x64 --on local --detach --json --args "--test-profile=$profileId"
./scripts/test-shell.ps1 -AppPid <上一步返回的PID> -Target local
```

脚本写入 `ui-test-artifacts/<workflow>/results.json` 与截图，scope 为指定 PID。点击及焦点检查需要解锁桌面并保持外部输入窗口前台；条件不具备时记录未验证。结束测试从托盘退出或使用 Debug `--exit-test` 激活参数，然后以正常参数启动用户配置。静态布局参数不会进行真实录音或识别。
