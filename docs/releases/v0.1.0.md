# VoxType v0.1.0 · 首个预览版

按住 **Ctrl + Shift + Space** 说话，松开后将识别结果输入当前窗口；**Esc** 取消。

## 包含功能

- Whisper 本地、R2T2 本机／局域网、OpenAI Compatible 三种识别服务。
- R2T2 录音期间临时预览，松开后以完整录音校正并交付文字。
- 可直接拖动的语音胶囊、位置记忆与输入区域避让、可选常驻麦克风入口。
- 深浅主题、失败重试、主窗口前台激活及新应用图标。
- Whisper base 模型下载／导入与校验，Whisper 和本机 R2T2 独立选择 CPU / Vulkan。

## 下载与使用

- **Setup.exe**：Windows 11 x64 当前用户安装，无需管理员权限。
- **Portable.zip**：完整解压后运行 `VoxType.App.exe`，在托盘打开设置；也可运行 `VoxType.App.exe --settings`。
- **SHA256SUMS.txt**：安装包、ZIP 与构建信息的 SHA-256。
- **build-info.json**：代码提交、版本与 Release 测试计数。

桌面包包含 .NET / Windows App SDK 运行时与 Whisper CPU / Vulkan 库，不包含模型或个人数据。Whisper 模型需下载或导入，CPU 需支持 AVX / AVX2 / FMA / F16C，并安装 x64 VC++ 2022 runtime；Vulkan 需要兼容驱动。本机 R2T2 的准备和启动额外需要 PowerShell 7、.NET 10 SDK 和约 1.63 GiB 模型。

安装包未签名，Windows 可能提示发布者未验证。卸载保留用户设置和模型；旧 MSIX 开发版的虚拟化数据不会自动迁移。
