# VoxType v0.1.3 · 浮窗背景拖动

本版简化固定在桌面的待机浮窗，并让浮窗空白区域支持直接拖动。

## 主要变化

- 移除待机入口左侧的拖动手柄，缩小麦克风入口。
- 按住录音浮窗或待机入口的空白背景即可移动；拖动区域随内容、状态和显示缩放自动调整。
- 麦克风、结束、重试和更多按钮保持原有点击功能。鼠标移到可拖动区域显示移动光标。
- 松开鼠标后保存浮窗位置；常驻入口和录音状态使用同一套位置设置。

## 下载与升级

- **VoxType-0.1.3-win-x64-Setup.exe**：Windows 11 x64 当前用户安装，无需管理员权限。
- **VoxType-0.1.3-win-x64-Portable.zip**：解压后运行 `VoxType.App.exe`。
- **VoxType-R2T2-Server-0.1.3-win-x64.zip**：仅在需要为其他设备提供 HTTP 服务时下载。
- **SHA256SUMS.txt**：核对所有发布包和构建信息。
- **build-info.json**：记录源提交、版本和 Release 测试计数。

升级前从托盘退出旧版 VoxType。设置和已下载模型会保留。浮窗位置按屏幕相对位置保存，在多个显示器或缩放比例变化后会自动调整。

安装包未进行 Authenticode 签名，Windows 可能显示发布者未验证。

## 验证范围

Release 自动测试及包内容检查结果见 `build-info.json` 和 `SHA256SUMS.txt`。自动检查覆盖空白拖动区域、交互按钮、待机入口和不同会话状态。实际鼠标拖动、真实麦克风输入、跨应用文本写入和干净机器安装仍需按各设备单独验收。
