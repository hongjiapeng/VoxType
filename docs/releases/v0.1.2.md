# VoxType v0.1.2 · 本机 R2T2 引擎与独立服务器

本版将 R2T2 推理协议和音频处理抽到桌面应用与独立 HTTP 服务器共用的核心库。本机模式直接调用共享库并管理自己的 llama-server；连接局域网或其他设备时，继续使用独立的 R2T2 Server 包。

## 主要变化

- 桌面包提供“R2T2 本机”模式，可选择 CPU / Vulkan、准备模型与运行时，并在设置中启动或停止本地引擎。
- 本机模式使用 `127.0.0.1:8273`，不启动 HTTP 适配器。若旧版独立服务仍占用该端口，会显示占用提示；应用不会结束其他进程。
- R2T2 Server 改为引用共享核心库，保留 HTTP / SSE 接口，作为单独的可选部署包发布。
- 原有服务器地址、模型和密钥仍按服务器连接配置保存；可在本机引擎和远程服务器之间选择。
- Release 包含 Windows x64 安装包、便携 ZIP、独立 R2T2 Server ZIP、构建信息与 SHA-256 校验清单。

## 下载与升级

- **VoxType-0.1.2-win-x64-Setup.exe**：Windows 11 x64 当前用户安装，无需管理员权限。
- **VoxType-0.1.2-win-x64-Portable.zip**：完整解压到本地目录后运行 `VoxType.App.exe`。
- **VoxType-R2T2-Server-0.1.2-win-x64.zip**：仅在需要为其他设备提供 HTTP 服务时下载。
- **SHA256SUMS.txt**：核对安装包、两个 ZIP 和构建信息。
- **build-info.json**：记录源提交、版本与 Release 测试计数。

升级前从托盘退出旧 VoxType。若之前启动的 R2T2 Server 仍在运行，它会继续占用自己的端口；本机模式与服务器模式不要同时争用 8273。设置与已下载模型保留。

桌面包随附 .NET、Windows App SDK、Whisper CPU/Vulkan 原生库及共享 R2T2 核心库。独立 Server 包随附自包含服务运行时和部署脚本。模型、llama 运行时、录音、个人配置和密钥均不包含在发布包中。包未签名，Windows 可能显示发布者未验证。

## 验证范围

Release 自动测试与包内容检查结果以 `build-info.json` 和校验清单为准。自动测试不代替真实麦克风、跨应用输入、干净机器安装及不同 GPU 的手工验收。Vulkan 运行仍要求兼容驱动并有足够内存／显存。
