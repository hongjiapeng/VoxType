# VoxType v0.1.1 · R2T2 安装与启动修复

修复 v0.1.0 安装后启动本机 R2T2 报 `Exception`、`Task` 等类型找不到的问题。原包在用户设备现场编译服务，且遗漏编译配置；本版已随包提供预编译服务及运行时。

## 主要变化

- 设置页内准备资源、显示下载／校验／模型加载状态，无需安装 PowerShell 7 或 .NET SDK，也不再弹出服务终端。
- 提供“停止 / 取消”，服务运行时防止重复启动和修改设备／目录；退出 VoxType 或任一服务失败时清理关联进程。
- 主程序与 R2T2 服务共用随包的相同 .NET 运行时文件，消除 ZIP 中约 35 MiB 的重复内容；冲突文件会让发布构建失败。
- 资源准备复用大小、格式及 SHA-256 校验通过的已有模型和运行时；模型仍由用户主动下载，约 1.63 GiB。
- 包含 v0.1.0 之后的悬浮层主题和会话切换修复。

## 下载与升级

- **VoxType-0.1.1-win-x64-Setup.exe**：Windows 11 x64 当前用户安装，无需管理员权限。已有安装可直接覆盖升级。
- **VoxType-0.1.1-win-x64-Portable.zip**：完整解压到一个新目录，运行 `VoxType.App.exe`，或使用 `--settings` 打开设置。
- **SHA256SUMS.txt**：安装包、便携 ZIP 和构建信息的 SHA-256。
- **build-info.json**：源提交、版本及 Release 测试计数。

升级前从托盘退出旧 VoxType；若旧版 R2T2 PowerShell 服务窗口仍在运行，请先按 Ctrl+C 停止。设置与已下载模型保留，不需要重新下载校验通过的模型。安装程序会清理旧版附带的服务源码。

桌面包随附 .NET、Windows App SDK、Whisper CPU/Vulkan 原生库和 R2T2 适配服务，不包含模型、录音、个人配置或密钥。Whisper CPU 仍需支持 AVX / AVX2 / FMA / F16C，并安装 x64 VC++ 2022 runtime；Vulkan 仍要求兼容驱动和足够内存／显存。包未签名，Windows 可能显示发布者未验证。

## 验证范围

Release 自动回归 **410 项通过**，包括脱离仓库的服务构建、共享运行时冲突／复用检查和启动后立即失败的状态保护。`winapp ui` 检查设置页初始状态、目录错误、后台启动、停止和立即重启；后台服务流程使用真实适配器与模拟推理进程验证，不采集麦克风。

真实 Vulkan 模型在本机出现内存分配失败；CPU 模式曾通过健康检查，但低系统提交余量下不能稳定重现。本版修复打包和服务管理，不保证解决设备驱动或内存不足问题。真实麦克风、跨应用输入、干净机器和不同显卡仍需按设备验收；预览文字可能改写，不承诺固定延迟。
